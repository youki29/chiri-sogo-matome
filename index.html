南アジアの宗教と印パ戦争

教科書 p.92〜

「1つのインド」は、なぜ宗教によって分かれたのだろう？

南アジアの宗教分布

国人口おもな宗教

インド北部のカシミール地方は、インドとパキスタンが領有を争っていて、地図帳では色が塗られていない（停戦ラインがある）。

印パ戦争の流れ

  • ネパール・ブータン以外は「1つのインド」だった。17世紀〜イギリスの支配を受ける
  • 1947年、イギリスから独立。しかしイギリスの支配方法が原因で、激しい宗教対立が起こる
  • ムスリムはヒンドゥー教徒からの仕返しを恐れ、ムスリムの多い地域の分離独立を主張。ヒンドゥー教徒は「1つのインド」を主張して内戦状態に
  • 結果、ムスリムの多い地域＝パキスタン（西パキスタン＋東パキスタン）、ヒンドゥー教徒の多い地域＝インドに2分された
カシミール問題
住民の8割はムスリムだったが、ヒンドゥー教徒の藩主が反対を押し切ってインドへの帰属を決定。住民はパキスタンに救助を求め、インド・パキスタン戦争が勃発。国連の仲介で停戦ラインが引かれたが、両国とも全域の領有を主張している。2019年8月には停戦ラインを越えて銃撃戦が起き、緊張が高まった。
  • 1971年、東パキスタンがバングラデシュとして独立を宣言 → 認めない西パキスタンと戦争。インドがバングラデシュ側に立って参戦し、印パ戦争が再燃
  • 仏教徒の多いセイロン島は、イギリス自治領としてインドから分離し、1972年スリランカとして独立
まとめ
「1つのインド」からパキスタンが分離、パキスタンからバングラデシュが分離、インドからスリランカが分離した。

ヨーロッパの歩みとEU

地理プリント45〜48　教科書 p.129〜

世界を支配したヨーロッパは、なぜ統合へ向かったのだろう？

世界の中心だったヨーロッパ

  • 15世紀末〜大航海時代：世界各地へ進出し、キリスト教や言語などの文化を広める
  • 18世紀後半〜産業革命：イギリスで始まる。蒸気機関の改良で石炭を燃料にした機械による大量生産が可能に
  • 産業革命を達成した国々は、資源を奪い、大量生産した商品を売りつける市場として、アジア・アフリカを植民地支配
  • 帝国主義がエスカレート → 植民地争奪戦 → 20世紀に二度の世界大戦。どちらも中心舞台はヨーロッパで、大荒廃

第二次世界大戦後：東西冷戦

  • アメリカ合衆国（西・資本主義）とソ連（東・社会主義）が2大勢力に
  • ヨーロッパに「鉄のカーテン」がおろされ、西ヨーロッパと東ヨーロッパに分かれた
  • 東西冷戦時代（1945〜1989／1991）：米ソの直接の戦争はなかったが、核戦争の危機
  • 1つの民族が2つの国に引き裂かれ、代理戦争に → 朝鮮戦争・ベトナム戦争。ドイツは戦争はなかったが東西に分断
  • 1991年ソ連崩壊で東西対立は終わったが、朝鮮半島の分断は今も続く

EU・ユーロ・シェンゲンの関係

  • EU加盟・シェンゲン加盟だがユーロ未導入：デンマーク・スウェーデン・ポーランド・チェコ・ハンガリー・ルーマニア
  • EU加盟だがシェンゲンに参加しない：アイルランド・キプロス
  • EU未加盟でシェンゲンのみ参加：スイス・ノルウェー・アイスランド・リヒテンシュタイン
  • どれにも入っていない：イギリス

EUの必要性と課題

地理プリント48・49

必要性：争いを避ける

大小さまざまな国が陸続きで隣り合い、国境問題や対立が絶えず、二度の世界大戦に。悲劇を繰り返さないため、「平和と共存・共栄」を目的に手を取り合った。

  • 1か国ずつでは小さい：日本よりGDPが多いのはドイツだけ、人口が多い国はない、面積が大きいのはフランス・スペイン・スウェーデン
  • EU全体では、GDPは日本の約5倍（アメリカに匹敵）、人口は約4倍（アメリカを抜く）、面積は約11倍
  • → EUとしてまとまった方が大国として有利に競争できる

GDPと1人当たりGDP

  • GDP＝国内総生産：国内で1年間に生産された財とサービスの合計（海外支店の生産や外国で活躍する日本人選手の給与は含まない）
  • 名目GDP（2025）上位：アメリカ・中国・ドイツ・日本・インド・イギリス・フランス・イタリア・ロシア・ブラジル
  • 1人当たりGDP上位：1位ルクセンブルク（人口が少なく貧困層が少ない）、2位アイルランド（税率が低くIT企業が進出）、3位スイス（金融・製薬・精密機械）、5位アイスランド（漁業・観光・地熱発電）、6位ノルウェー（北海油田）、8位デンマーク、9位オランダ
  • ドイツは国単位では欧州トップだが、人口も最大なので1人当たりでは第2ランク
  • 西・北ヨーロッパが高く、南（イタリア・スペイン・ポルトガル・ギリシャ）、東（ルーマニア・ブルガリアなど）ほど低い

EUの課題

西ヨーロッパ東ヨーロッパ
経済水準高い低い
賃金高い低い
移動するもの西 → 東へ 工場東 → 西へ 労働力
  • 西ヨーロッパでは、安い労働力の流入で自国民の失業率が上昇。工場の転出で産業の空洞化（雇用の減少、関連産業の衰退）
  • トルコがEU加盟を申請中だが、話し合いは進まない
外国人労働者と宗教・文化の摩擦
第二次世界大戦後の経済成長期、労働力不足を外国人労働者が支えた。
ドイツ ← トルコ（ドイツではガストアルバイターと呼ばれる）／フランス ← 北アフリカ（アルジェリア・モロッコなど）／イギリス ← インド・カリブ海諸国
いまは移民の子や孫の世代になり、ヨーロッパの人々には多文化との共存の問題、ヨーロッパ生まれの外国人にはアイデンティティの問題がある。フランスでは公共の場で頭を覆うもの（イスラームの習慣）が禁止された。

イギリス・フランス

地理プリント50　地図帳 p.53・63

イギリス

  • 正式名称：グレートブリテン及び北アイルランド連合王国（United Kingdom＝U.K.）
  • イングランド王国が13世紀にウェールズを併合、18世紀にスコットランドと合併 → グレートブリテン王国。国旗（ユニオンジャック）は左右対称ではない
  • 19世紀にアイルランドを併合 → 1921年アイルランド独立。しかし北アイルランドはGB島からの移民が多く、イギリス領に
アイルランド紛争（北アイルランドの帰属をめぐる争い）
住民の40%＝アイルランド系・カトリック（アイルランドへ返せ）
住民の60%＝イギリス系・プロテスタント（イギリスのままで）
テロの応酬で約3200人が死亡。1998年に和平。
  • ロンドン：首都。テムズ川の港湾都市。国際金融都市
  • リヴァプール：三角貿易（奴隷貿易）の拠点港。産業革命期には植民地との交易港
  • マンチェスター：産業革命期に綿織物工業が発達
  • ケルト系民族：アイルランド・スコットランド・ウェールズ・フランスのブルターニュ半島。かつては大陸に広く住んでいたが、英語（ゲルマン語系）に押されて西の端へ。独自の言語（ケルト語系）と文化を持つ

フランス

  • フランス＝EU最大の農業国。北の国々は氷河の侵食で表土が流されやせた土地、南は地中海性気候で夏が高温乾燥 → フランスは農業に有利
  • パリ盆地は小麦の産地（小麦輸出量は世界3位）
  • ブドウ栽培 → ワインの生産量はイタリア・スペインと世界一を争う。地域ごとの味わい、高級志向で高値で輸出
  • パリ：首都。セーヌ川の水運。中心部は伝統的な低い街並みを守り、副都心ラ・デファンス地区に高層ビルを集めた
  • トゥールーズ：エアバス社（航空機産業）、大学都市
  • マルセイユ：フランス第2の都市、最大の貿易港
  • カンヌ：国際映画祭。カンヌ〜ニース〜モナコ＝コート・ダジュール（紺碧海岸）、歴史の古いリゾート地
  • ドイツとの国境地帯：アルザス・ロレーヌ（鉄鉱石の産地）、ドイツ側のザール（石炭の産地）。両国で領有をめぐる争いが繰り返された

ドイツ・オランダ・スイス

地理プリント51　地図帳 p.53・55

ドイツ

  • EU最大の工業国。自動車・医薬品・精密機械（乗用車輸出量は世界4位）
  • ベルリン：首都・最大の都市。冷戦の象徴「ベルリンの壁」があった
  • ハンブルク：ドイツ最大の貿易港、第2の都市（エルベ川）
  • ヴォルフスブルク：フォルクスワーゲンの企業城下町
  • フランクフルト：EUの金融の中心。欧州中央銀行
  • シュツットガルト：ベンツ・ポルシェ（自動車）
  • ミュンヘン：南部バイエルン州の中心、第3の都市。シーメンス（機械）・BMW（自動車）・ビール

オランダ

  • ネーデルラント＝「低い土地」の意味。国土の約4分の1は海面より低い
  • 国土の5分の1以上は干拓でつくられた土地＝ポルダー。堤防内の水をくみ出すのに風車が使われた
  • 穀物栽培に向かない土地 → 牧草栽培 → 乳牛 → 酪農（チーズ）
  • 海岸沿いの砂丘地帯 → 園芸農業（花・野菜）
  • アムステルダム：首都。標高は海面下、運河の街
  • ロッテルダム：第2の都市。外港のユーロポートはライン川の河口にあるヨーロッパ最大の貿易港で、ドイツ・スイスの貿易の窓口にもなる
  • マーストリヒト：マーストリヒト条約が結ばれた都市

スイス

  • 大国に囲まれた小国として永世中立国を貫くため、国民皆兵。山岳地帯が多く、古くからの産業は他国への「傭兵」
  • さまざまな国の通貨が持ちこまれた → 金融業が盛んに
  • 農業は酪農。夏はアルプスの高山の牧草地で放牧、冬はふもとの村で舎飼い＝移牧
  • 多民族・多言語国家：ドイツ語（約64%）、フランス語（約20%）、イタリア語、ロマンシュ語。小学校から別の公用語を学ぶ
  • バーゼル：ライン川に面したスイス最大の河港。化学工業
  • チューリヒ：スイス最大の都市。ニューヨーク・ロンドンと並ぶ国際金融都市（銀行・保険）
  • ジュネーヴ：レマン湖に面する国際都市。ILO・WHO・国際赤十字など国際機関の本部

イタリア・スペイン

イタリア

  • 北部＝工業の三角地帯：トリノ（フィアット社・自動車）、ミラノ（第2の都市・経済とファッション）、ジェノヴァ（最大の貿易港）
  • 豊かな北部と貧しい南部の経済格差＝南北問題。北部は自分たちの税金が南部に流れることに不満
  • 南部の中心都市ナポリ（「ナポリを見てから死ね」）。国家事業「バノーニ計画」で南部を振興 → タラントに巨大な製鉄所
  • 第三のイタリア：伝統的な職人技術にもとづく地場産業が近年のイタリア経済を支える
    • ヴェネツィア：運河の街（水の都）、ガラス細工
    • ボローニャ：皮革産業（靴・バッグ）
    • クレモナ：ストラディバリを生んだ楽器の都
    • フィレンツェ：芸術の都、ルネサンス期からの古都

スペイン

  • 標準語はカスティーリャ語（スペイン語）。ほかに地方の言語がある（バスク語以外はラテン語系）
  • 1939〜1975年はフランコ将軍の独裁 → 地方の言語は厳しく弾圧された（取り締まれなかったのはサッカー場のサポーター席だけ）
地方ポイント
A バスクピレネー山脈の両側（スペイン北部〜フランス南部）。バスク語はインド・ヨーロッパ語族にも入らない独自の言語。中心都市ビルバオ（鉄鋼業）。分離独立運動が根強い
B カタルーニャ独自の文化を持つ先進工業地域。中心都市バルセロナ（第2の都市・最大の貿易港、ガウディの建築）。2017年に住民投票で独立を決めたが、政府の弾圧で断念
C ガリシアリアス海岸（「リア」はこの地方の入り江の名）。サンティアゴ・デ・コンポステーラはカトリックの巡礼地
D アンダルシアフラメンコ・闘牛。約800年イスラーム王朝に支配され、ヨーロッパとイスラームの文化が融合。セビリア（コロンブスが出港した河港）、グラナダ（アルハンブラ宮殿）
  • ジブラルタル：イギリス領。海上交通の要所として、スペインは返還を求めている
  • セウタ：ジブラルタルの対岸、アフリカ大陸側（モロッコ側）のスペイン領

都市

  • サンクトペテルブルク：バルト海（フィンランド湾）に面した港湾都市。ロシア帝国の都。王宮はエルミタージュ美術館に。「ピョートル大帝の街」の意味
  • モスクワ：ロシアの首都。クレムリン宮殿、ボリショイ劇場
  • キーウ：ウクライナの首都（ロシア語読みはキエフ）
  • イルクーツク：バイカル湖近くの工業都市。シベリアの中心
  • オイミャコン：北半球の寒極
  • ハバロフスク：アムール川に面した極東ロシア最大の都市。中国国境
  • ウラジオストク：日本海に面する港湾都市。シベリア鉄道の東の起点（モスクワまで鉄道で7日）

ロシアの歴史：不凍港を求め続けた

  • 15世紀のモスクワ周辺から、16〜19世紀にかけてシベリア・極東へ領土を拡大。江戸時代末には日本のすぐ近くに
  • 北のバルト海、東のウラジオストクは冬に凍る → 南下政策：遼東半島（清）・朝鮮半島へ進出を狙う → 1904年日露戦争
  • 続いてバルカン半島を狙い、1914年第一次世界大戦が勃発
  • 大戦中、長引く戦争と皇帝支配に耐えかね、皇帝支配を倒すロシア革命（1917年）
ソ連（1922〜1991）
1922年 ソビエト社会主義共和国連邦（ソ連）誕生。世界初の社会主義国家（面積は日本の約60倍）。
初代指導者レーニンは平等な社会を理想とし、産業の国有化・農地の共有化を進め、政府が生産から分配まで統制する計画経済を推進。
第二次世界大戦後は、アメリカに対抗するため軍事・宇宙開発を国民経済より優先。支配者層による格差、競争がなく生産性も上がらない → 社会も経済も停滞。
1991年、バルト3国の独立をきっかけにソ連崩壊 → 15の国に分裂。残ったのが現在のロシア連邦（面積は日本の約45倍）。
